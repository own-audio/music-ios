# App Store listing

Text per language (`en-US/`, `cs/`), in the store's fields. Screenshots: to do, from a server
whose music may be shown publicly (not a personal library with commercial covers).

Store details that live in App Store Connect:

- **Category:** Music.
- **Age rating:** 4+ (the app shows whatever the user's own server holds).
- **Price:** free, no in-app purchases.
- **App privacy:** Data Not Collected. The app sends nothing to anyone but the servers the
  user adds.
- **Support URL:** https://github.com/own-audio/jelly-ios/issues
- **Marketing URL:** https://www.own.audio
- **Review notes:** Jellyfin's public demo server works for review: address
  `https://demo.jellyfin.org/stable`, user `demo`, empty password. It holds a few freely
  licensed albums.

Limits: name and subtitle 30 characters, keywords 100, promotional text 170, description
4000. "Jellyfin" appears only as "for Jellyfin", with a line that the app isn't affiliated
with the project.

CarPlay is left out of the description until it has been checked on a CarPlay screen and the
entitlement is granted.
